# AI Interview Coach

AI-powered interview preparation platform built with React, TypeScript, Node.js, Express, and OpenAI.

## Features

- Upload CVs (PDF and DOCX)
- AI-generated interview questions tailored to the candidate
- Hebrew and English support
- Voice recording for answers
- Text-to-speech for interview questions
- AI-powered interview feedback
- Interview history tracking
- PDF interview reports
- Dark and Light mode

## Technologies

Frontend:
- React
- TypeScript
- Axios
- CSS

Backend:
- Node.js
- Express
- OpenAI API
- Multer
- Mammoth
- PDF Parse

## Installation

Client:

npm install
npm run dev

Server:

npm install
npm run dev
